## 「触らない方がいい」 リスト

仕様通り or 既知の理由で意図的にこうなっている箇所。 リファクタ提案禁止。

- `src/rehype/nun-structure.ts:139-150` の `<template data-fn>` 設置 — DOM-3 で sup-scoped 化はするが、 `<aside>` 化や sibling 配置の根本変更は禁止。 HTML5 adoption agency 仕様による技術的必然
- `src/rehype/nun-code-block.ts:58-66` の diff `\n` 処理 — `\n` 剥がさず inline + box-decoration-break で扱う設計判断 (コメントに詳細)。 `display: block` 化は禁止
- `src/rehype/templates.ts:14-21` の `inlineProcessor` — 本体 pipeline と同じ拡張セットだが処理対象が違う (block vs inline)。 統合提案禁止
- `src/styles/templates/default.css:65-72` の空ルール — CSS-7 で削除提案するが、 コメント内容は load-bearing。 削除時はコメントを直前ルールに保持
- `src/styles/base.css:14-22` の `height: 100%; height: 100dvh` 2 行宣言 — 旧ブラウザフォールバックとして意図的
- `src/rehype/extract-scopes.ts:50-64` の `parentRangeEnd` 引数 — 末尾サブスコープが親範囲を超えないようにする精密制御
- `src/rehype/nun-structure.ts:36` の `sectionIndex = { value: 0 }` — mutable wrapper 経由でカウンタを再帰関数間で共有する意図
- `src/micromark/mark.ts:135-136` の `before`/`after` classification — micromark の attention parsing 仕様通り
- `src/rehype/nun-card.ts:117` の `timeout: 8` — open-graph-scraper の秒指定。 値変更禁止
- `src/client/index.ts:131` の `if (iteration >= 10) return` — spec structure.md:87 に明記された値
