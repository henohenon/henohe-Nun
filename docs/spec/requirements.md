# ユーザー要件

## ナビゲーション
基本的に、各ページが画面いっぱいに表示され、urlは`#<n>`で管理される。該当ページ/section以外は`display:none;`。一部出力時には別のcssを適用して全ページが見えるようにする。
- `←` / `→` / `↑` / `↓` / `Space` / `PageDown` / `w` / `a` / `s` / `d` キー・タッチスワイプ・マウスホイールで移動
- `Home` / `End` で最初／最後へ
- `Enter` でフルスクリーントグル
- 画面左右クリック（フルスクリーン時）で前後移動

## 出力
- 静的HTML
  - メイン
- PDF
  - 色んなとこに出す時用
- Webp
  - 主にサムネ用

## インデックスページ
デッキ一覧ページ。各デッキのサムネイルとタイトルを表示し、日付順でソートする。

## OGP
生成されるHTMLに OGP メタタグ（og:title, og:image など）を出力する。
タイトルや説明はデッキの内容から自動生成し、サムネイル画像は出力した Webp を使う。
SNS やチャットでURLを共有した際にプレビューが表示されるようにする。

## ホットリロード
開発時のmd2htmlホットリロード。必須。
